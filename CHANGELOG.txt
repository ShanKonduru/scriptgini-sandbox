      New Page Object class: LoginPage
      Implements complete SSO login flow through Microsoft authentication:
        - navigate() - Navigate to Pega authentication page

        - enter_email() - Fill email in Microsoft SSO
        - click_next() - Proceed to password page
        - enter_password() - Fill password
        - click_sign_in() - Complete authentication
        - accept_cookies() - Handle cookies dialog
        - login() - Complete end-to-end login workflow
      Uses real observed selectors captured via Playwright MCP tools.

  - pages/cars_by_release_page.py
      New Page Object class: CarsByReleasePage
      Implements Cars By Release page interactions within Pega iframe:
        - wait_for_page_load() - Handle Pega Constellation framework loading
        - select_status() - Select status filter (handles both native and custom dropdowns)
        - enter_waybill_date_from() - Fill waybill date filter
        - click_filter_button() - Apply filters
        - select_first_equipment() - Select equipment via checkbox
        - click_actions_button() - Open actions menu

        - verify_dropdown_options() - Verify expected options are present
        - is_option_present() - Check specific option existence
      Handles Pega iframe-based content using frame_locator().

      Reads credentials from environment: DSP_USERNAME, DSP_PASSWORD, DSP_BASE_URL
